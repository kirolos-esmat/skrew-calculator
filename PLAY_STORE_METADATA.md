## Short description

Track Skrew scores across rounds with a simple Arabic and English companion.

## Full description

Keep the game moving and leave the scorekeeping to Skrew Calculator. Create a game, add the players, enter scores as each round finishes, and review the standings and saved history when the cards are down.

Features:

- Set up games for 2–10 players and 1–10 rounds.
- Enter scores round by round with 2× and 4× controls.
- Follow standings throughout the game and see the winner at the end.
- Return to completed games and past winners.
- Switch between Arabic and English.
- Use a clear, touch-friendly mobile interface made for the table.
